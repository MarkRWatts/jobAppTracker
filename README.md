# Job Application Tracker

A personal, single-user web app for tracking job applications — status pipeline, dates/times at every stage, CV/cover-letter usage, and links out to supporting material (CV, STAR examples) in Confluence.

Not yet scaffolded. See [`../jobAppTracker-docs/project-plan.md`](../jobAppTracker-docs/project-plan.md) for the full plan (architecture, data model, phases).
